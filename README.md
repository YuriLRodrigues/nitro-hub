# NITRO HUB — downloads

App grátis, em português, para Windows 10 e 11 (64 bits): overlay de FPS, Modo jogo, otimizações do Windows com botão de
desfazer, sensores com alertas, overclock com áreas de risco e mais.

- **Site:** <https://nitro-hub-lp.vercel.app>
- **Baixar:** [NitroHub-Setup.exe (versão mais recente)](https://github.com/YuriLRodrigues/nitro-hub/releases/latest/download/NitroHub-Setup.exe)
  · [todas as versões](https://github.com/YuriLRodrigues/nitro-hub/releases)

Este repositório guarda só os instaladores (nas Releases). O app se atualiza sozinho a partir daqui.

## Confira se o arquivo é o oficial

Baixe só pelo site ou pelas Releases deste repositório. No PowerShell, na pasta do arquivo:

```powershell
Get-FileHash .\NitroHub-Setup.exe
```

O resultado tem que ser igual ao do `SHA256SUMS.txt` (e das notas) da release que você baixou.

## Cuidado com cópias falsas

O NITRO HUB **nunca**:

- é enviado em `.zip` ou `.rar` com senha, nem por link no Discord;
- pede login do Discord, da Steam, do e-mail ou do banco;
- pede para desativar o antivírus;
- vem junto de "jogos" ou programas para testar.

Recebeu um arquivo assim? Não abra. Se já abriu, troque as senhas por outro aparelho, a começar pelo Discord.

## Problemas e sugestões

Abra uma [issue](https://github.com/YuriLRodrigues/nitro-hub/issues) contando o que aconteceu, a versão do app
(em Sobre) e o seu Windows.
